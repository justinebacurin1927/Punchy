# Punchy 0.1.2 — download detection repair

Download **Punchy-0.1.2-debug.apk** under **Assets** and install over your existing Punchy app. Your position, size and border thickness settings are preserved.

## Changes

- Reads custom notification progress bars and text percentages as well as standard numeric progress fields, including large counters.
- Handles progress present only on a group summary, without double-counting a readable child.
- Includes all progress sources by default; explicitly saved app selections remain intact.
- Adds **Download apps → Download detection** to show notification delivery, excluded sources and readable progress. Reports omit message text and filenames and can be copied manually.
- Pausing music restores your normal black-filled indicator. A paused session no longer forces the empty wide outline. Playback controls remain usable in an already-open combined card.

## Test on your HONOR

1. Install the update over the old app, keep Punchy enabled and start an actual Play Store or video-downloader download.
2. If no indicator appears, open **Download detection**, tap **Allow all progress sources**, then **Refresh notifications** while the download continues.
3. If still missing, tap **Copy detection report** and share that text in our conversation. This will show whether MagicOS delivers the notification and which progress fields Punchy sees.
4. Pause music: the normal black-filled shape should return. Resume playback to use the wide outline.

The expanded Android 14 emulator checks cover multiple notification formats, app filtering, group summaries and paused playback. Actual notifications on the HONOR still require this retest; a successful preview alone does not establish download detection. No root, Xposed, network permission, screen reading or gesture capability is added.
