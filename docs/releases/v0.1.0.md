# Punchy 0.1.0 — first personal APK

Download **Punchy-0.1.0-debug.apk** from **Assets** below, then open it on your phone to install.

For the HONOR X7c running MagicOS 8.0 / Android 14. Requires Android 14 or newer; no root or Xposed.

## Setup

1. Open Punchy and allow **Notification access**.
2. Enable **Punchy progress ring** in **Accessibility** settings.
3. Turn on Punchy and use **Preview on phone** to adjust circle/capsule size and alignment.
4. Add the **Punchy** Quick Settings tile for on/off control.

If Android blocks access for the sideloaded app, open **Settings → Apps → Punchy → menu → Allow restricted settings**, then retry setup. MagicOS wording may differ.

[Full install guide](https://github.com/justinebacurin1927/Punchy/blob/main/docs/INSTALL.md)

## Included

- Download progress from selected apps' notifications.
- Circle or capsule border, preview and calibration.
- In-app and Quick Settings toggles.
- Multiple-download tracking and unknown-total progress.
- Automatic hiding while idle, off, locked, screen off or in landscape.

This is a separate transparent overlay. Native HONOR Magic Capsule integration, physical cutout alignment and MagicOS background survival remain unverified on the actual phone.
