# Punchy 0.1.5 — Accessibility pause and project transparency

Install **Punchy-0.1.5-debug.apk** over your existing Punchy installation to keep calibration and app choices.

## Turn off before banking

Use **Turn off Accessibility** below the main status, or tap the ring and use that button in the expanded download/music card. This disables Punchy's actual Android Accessibility service, stops the ring and closes the card. Notification access stays enabled.

To use the ring again, open Punchy → **Enable Accessibility**, enable **Punchy progress ring** in Android settings, return to Punchy, then turn on **Enable Punchy**. Android requires your action to enable the service. The ordinary switch and existing Quick Settings tile only control display.

A bank may require further steps; this update is not a guarantee of bank acceptance or an exception from its protections.
